8. KAGGLE DATASET LICENSE CHECK
================================================================================
Dataset: "Gym Exercise Dataset" — niharika41298/gym-exercise-data
URL: https://www.kaggle.com/datasets/niharika41298/gym-exercise-data
File used: server/data/raw/gym-exercise-data/megaGymDataset.csv (2,918 rows;
  columns Title, Desc, Type, BodyPart, Equipment, Level, Rating, RatingDesc).

Findings:
- Web search result metadata for the dataset page reports the license as
  CC0-1.0 (Public Domain Dedication).
- I could NOT confirm this on the Kaggle page itself (it is behind a bot check), and
  the mirrors checked (Gigasheet, Baselight) state no license. Treat CC0 as
  "reported, not verified".
- The repo records no license: normalizeExercises.ts writes `license: null` for
  every Kaggle record.
- Provenance is not stated anywhere I could access. The columns Rating/RatingDesc
  (862 rows rated "Average") and the editorial style of the descriptions suggest the
  data was collected from an existing exercise website. This is an inference, not
  verified. A CC0 dedication by the uploader only covers rights the uploader had.
- Exposure: 1,368 rows have free-text descriptions (Desc) — the part most likely
  to be someone's copyrighted text. Names, body part, equipment, level are facts
  and low-risk.

What the importer copies today (normalizeExercises.ts):
- Title -> name, BodyPart -> primaryMuscles/category, Equipment -> equipment,
  Level -> difficulty, Type -> movementType (required; rows without it are skipped).
- Desc -> instructions.execution (copied text).
- The entire CSV row, incl. Desc, Rating, RatingDesc -> source.raw (copied text + ratings).

OWNER DECISION (A1): license not confirmed -> dataset treated as NOT cleared for
commercial use. Keep only factual fields: name, body part, equipment, level.
Drop Desc and any other copied text or ratings.

Note on Type: Type (e.g. "Strength", "Cardio") is a one-word factual category like
Level, and the schema requires movementType. The Phase 1 plan keeps it for that
reason. Owner confirmed: keep Type / movementType as is.

Phase 1 actions: stop mapping Desc, store only factual fields in source.raw, never
import Rating/RatingDesc, update tests, set source.license to "unconfirmed — facts
only", rewrite THIRD_PARTY_CONTENT.md with the decision and reason.
Backlog: original exercise descriptions (AI draft, coach-approved). Until then the
coach's per-exercise notes are the instructions trainees see.
