1. SUMMARY
================================================================================
- Removed the ATLAS website: Landing, Showcase, Navbar, Footer, scroll-reveal hook,
  unused CSS and website-only assets. "/" now redirects to /login.
- Before deleting anything, adapted the onboarding dependencies: PageLayout is now a
  minimal layout (no Navbar/Footer), and AuthCard and Sidebar use a new single Logo
  component ("SISTEM" text placeholder). Sidebar has no Exercises link, and logout goes to /login.
- Removed the AI chat (client CoachWidget + server aiCoach + /api/coach + @google/genai)
  and the separate activity logger (client + server + /api/activities). Decoupled
  DashboardCalendar, MonthCalendar and AchievementBadges from activities.
- Removed all RepDB content. The Kaggle import keeps facts only (name, body part,
  equipment, level, type). Rewrote THIRD_PARTY_CONTENT.md with the decision.
- Renamed ATLAS -> Sistem (onboarding copy "ATLAS" word only, package names, title,
  server log, email sender and reset email, token key). Fixed the 2 client TS errors.
  Removed three.js packages. Added .env.example files and a short Sistem README.
- Final state: client build OK, client lint OK (0 errors, 3 pre-existing warnings),
  server build OK, server tests 45/45 passing.

4. NOTES ON THE EXERCISE CHANGES
================================================================================
Kaggle facts only (normalizeExercises.ts):
- instructions.* are always empty; Desc is never read. RawExerciseRow no longer
  declares Desc/Rating/RatingDesc, so no code can read them by mistake.
- source.raw = { Title, Type, BodyPart, Equipment, Level } only.
- source.license = "unconfirmed — facts only" (exported constant KAGGLE_LICENSE).
- The dedup "prefer the variant with a description" rule no longer applies
  (none has one); the first record of a duplicate group is kept.
Search sorting: the contentTier sort (enhanced first, then name) is unchanged because
the field is kept. With no 'enhanced' records it falls through to name order. Two
new tests cover this for the list path and for search score ties.
